# Ruchit Soni — Robotics Engineering Portfolio

## Publish with GitHub Pages
1. Create a **public** GitHub repository (for example, `my-portfolio`).
2. Upload `index.html` and the complete `assets` folder. Keep the folder structure unchanged.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. After deployment, open the URL shown in Settings → Pages.

The HTML file uses relative paths such as `assets/asset-01.mp4`. Do not upload `index.html` without the assets folder.

## Local preview
Open `index.html` in a modern browser. If browser restrictions affect any features, run a local static server from this folder, e.g. `python -m http.server 8000`, then visit `http://localhost:8000`.
